PUZZLE PICTURES GO IN THIS FOLDER

One collage picture per puzzle (your four photos already joined into one).
Name each file after the answer, in small letters:

  jollof.jpg      amala.jpg      supereagles.png

JPG, PNG or WEBP all work. Capital letters in the name do not matter.
No editing of puzzles.json is needed. A puzzle with no picture here shows
four emoji tiles instead, so the game works while you add pictures.

Players never see these file names. The game hands pictures out through
private links, so nobody can learn an answer from a file name.

Easier: use the Admin page (Me > Admin: manage puzzles) to upload a picture
for any puzzle. It saves the file here for you.

Run "npm run images" to see which puzzles still need a picture.
